# Referencias visuales Android

`figma_svg/` conserva los cuatro SVG de navegación: mapa, sensor, aprende y cuenta.
La aplicación utiliza sus versiones rasterizadas en `app/src/main/res/drawable-nodpi/`.

Esta carpeta es material de referencia de diseño; no es un módulo Gradle.
Para cambiar la interfaz consulta [el README Android](../README.md). La procedencia
y las diferencias tipográficas de la entrega original figuran en
[las notas históricas](../../../doc/historico/android/LEEME_PRIMERO.md).
